How to Use WordPrep

1. Add a Main Word: Enter one Main Word and press Enter to display the starting-letter boxes.

2. Browse by letter: The final list is organized into nine letter boxes: A, B, D, F, I, N, O, T and U. Select a letter to display its prepositions.

3. 2+ Preposition OFF: Open a letter and click one preposition. That single Word–Preposition pair is saved immediately.

4. 2+ Preposition ON: Select at least two prepositions. Use Back to Letters to choose prepositions from another letter; previous selections remain checked. Save Selected becomes active after two or more selections.

5. Existing pairs: A preposition already saved for the same Main Word is marked Saved and cannot be added again.

6. MCQ rule: Each saved pair can create its own question. Every other preposition belonging to that same Main Word is excluded from the distractors.

7. Explanation: After answering, a reference box displays the Main Word and all imported prepositions associated with it. The page automatically scrolls to this box.

8. Four options and learning: A question is created only when three other unique, valid distractors are available. Random practice retains the New:Corrected:Mistaken = 4:1:5 learning ratio.

9. Backup: Export JSON to save your pairs and learning progress. The final 40-item Preposition Master List is grouped into nine starting-letter boxes.

Note: WordPrep uses the pairs you import as your answer key. It does not independently verify whether each English word–preposition combination is grammatically correct.

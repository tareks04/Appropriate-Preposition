How to Use WordPrep

1. Add pairs: Write Main Words in the first box and their corresponding Prepositions in the second box. Keep the same line order.

2. Word Guide: The guide beside the Preposition box automatically displays Main Words that still need a Preposition.

3. Live update: The Guide updates with every typed character. A word disappears when its corresponding Preposition line is no longer empty. Clearing that Preposition makes the word appear again.

4. Multiple prepositions: Repeat the same Main Word on additional lines to add more Prepositions.

5. MCQ rule: All other Prepositions belonging to the same Main Word are excluded from its distractors.

6. Four options: A question is created only when three other unique and valid distractors are available.

7. Explanation: After answering, the page automatically scrolls to a reference box showing the Main Word and all its imported Prepositions.

8. Capitalization: The first letter of the Main Word is capitalized in the MCQ and reference box.

9. Backup: Export JSON to save your pairs and learning progress.

Note: WordPrep uses your imported pairs as its answer key. It does not independently verify grammatical correctness.
